# Scripts de simulation — le sous-process de rédaction

*Créé le 2026-09-22, demande de l'utilisateur : « rédaction du script de simulation : doit être
normé, à calibrer finement avec toi, 10 questions. (sous-process : rédaction du script de la démo) ».*

Un script de simulation vit ici, un fichier par script, avec sa date et la simulation qu'il a
servie. C'est le seul endroit où l'on peut relire, des mois plus tard, **comment** une simulation
a été jouée — et pas seulement ce qu'elle a produit.

## Ce que l'utilisateur a déjà tranché sur le contenu

- **La simulation doit être RAPIDE.** Il n'est pas nécessaire de respecter exactement le temps réel
  du jeu : ce qu'on cherche, ce sont les moments narratifs, pas la durée.
- **La partie où l'agent se fait passer pour le visiteur doit être SOIGNÉE et CRÉDIBLE.** Défaut
  réel déjà constaté sur une version précédente : les mêmes phrases étaient envoyées aux deux
  personnages, ce qui se voit immédiatement à la lecture et fausse tout jugement sur leurs
  réactions — deux personnalités distinctes recevant un stimulus identique ne peuvent pas être
  comparées honnêtement.

## Ce qui reste à calibrer

La norme complète du script fait l'objet d'un round de dix questions, à poser avant toute
rédaction. Tant que ces réponses n'existent pas, aucun script écrit ici n'est « normé » — il est
seulement archivé.
