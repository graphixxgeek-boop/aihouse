# THE-KING — archives des textes fondateurs remplacés

**CE DOSSIER EST UNE ARCHIVE, JAMAIS UNE SOURCE DE VÉRITÉ sur ce qui fait loi aujourd'hui.**
C'est le principe G3 du projet appliqué à THE-KING lui-même : *le passé se garde entièrement, et
ne fait jamais autorité*. Rien n'y est résumé — un texte fondateur remplacé est conservé
**verbatim**, parce que la raison qui l'avait fait écrire disparaîtrait dans un résumé.

**Pourquoi chez THE-KING et pas ailleurs** : il est le veilleur du texte fondateur et le gardien
de son histoire depuis le 2026-09-21. Son rôle déclaré est de « conserver un historique de
l'évolution du document » — archiver la version remplacée EST ce rôle, pas un rôle de plus.
