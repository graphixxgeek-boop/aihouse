# Recherches web — le registre

**Pourquoi ce dossier existe.** Il a posé la règle que **toute recherche web s'enregistre sur
disque**, avec effet rétroactif. Elle est restée **plusieurs jours sans jamais être appliquée** :
trois documents la citaient comme « posée, jamais portée ». Une règle qu'aucun fichier ne
matérialise n'existe plus à la session suivante (Article 27) — ce dossier est sa matérialisation.

**Ce que porte chaque relevé, et pourquoi chaque pièce compte :**

| Pièce | Pourquoi elle est obligatoire |
|---|---|
| la **requête exacte** | une autre formulation rend d'autres résultats — sans elle, rien n'est rejouable |
| la **date** | le droit, les prix et les services bougent ; un relevé sans date se lit comme s'il était vrai aujourd'hui |
| les **sources avec leur lien** | pour rouvrir et vérifier, jamais pour me croire |
| ce qui **en est ressorti** | et jamais ce que j'en conclus : l'analyse est un autre document, et les mélanger rend le relevé invérifiable |

**La frontière, écrite des deux côtés** : ici on lit **CE QUE LE WEB A RENDU**. Ce que le projet
en fait vit ailleurs, dans le document d'analyse que chaque relevé nomme.
