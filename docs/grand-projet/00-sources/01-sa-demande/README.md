# Ici vont les DEUX fichiers qu'il a écrits lui-même

*(La demande + les questions. Dossier volontairement à part, et c'est la règle la plus importante
du GRAND PROJET.)*

**Ce dossier a un statut que l'autre n'a pas.** Ce qui est ici est SA PAROLE : elle prime sur tout
le reste du corpus, elle ne se résume pas, et un document préparé qui semblerait la contredire ne la
corrige jamais — c'est elle qui tranche.

**Rien ici ne se modifie.** Les fichiers y restent tels qu'il les a déposés. Ce que j'en tire vit
ailleurs : dans `01-absorption/`, dans `02-strategie/`, dans `03-plan-daction/`.

**Comment les déposer**, sans ligne de commande : sur GitHub, ouvrir ce dossier, « Add file » →
« Upload files », glisser-déposer, valider.
