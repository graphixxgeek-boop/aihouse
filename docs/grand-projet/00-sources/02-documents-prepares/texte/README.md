## POURQUOI CETTE CONVERSION EXISTE

Les originaux sont des `.docx` dans une archive. **Un `.docx` est illisible pour tous les outils de
recherche du dépôt** : `data-archangel notes`, `find-booster`, ABRAHAM, HARMONIA — aucun ne sait
l'ouvrir. Un document que la bibliothèque ne peut pas lire est un document qui n'existe qu'à
moitié, et c'est exactement le contraire de ce que l'utilisateur demande en les déposant ici :
« cette bibliothèque partagée, c'est un trésor que tu ne dois pas négliger ».

Les `.docx` originaux restent à côté, jamais supprimés. **Cette version texte ne les remplace pas,
elle les rend atteignables.**

## LEUR SOURCE, ET ELLE CHANGE COMMENT ON LES LIT

Produits avec **Copilot entreprise**, dans une démarche assumée : « Je pioche un peu partout
(Gemini, ChatGPT, Copilot) pour que notre travail porte une vision large sans angles morts, et
aussi pour avoir differents avis, ne pas rester enfermé dans une bulle ».

**Leur statut est donc celui de tous ses documents apportés : une AIDE, JAMAIS une règle, une
consigne, un ordre ni un modèle rigide.** Seuls ses deux fichiers prioritaires
(`COMMANDE IMPORTANTE.docx`, `QUESTIONS.docx`) font autorité. Un document de gouvernance
d'entreprise a l'air d'un règlement ; celui-ci est un avis, et il se discute.

**Un point à garder en tête en les lisant** : Copilot dit lui-même avoir retrouvé « 8 738 résultats
dans les fichiers » de l'utilisateur. Une partie de ce qu'il rend est donc la pensée de
l'utilisateur qui lui revient reformulée — ce n'est pas un regard entièrement extérieur, et ça
compte quand on cherche les divergences plutôt que les confirmations.
