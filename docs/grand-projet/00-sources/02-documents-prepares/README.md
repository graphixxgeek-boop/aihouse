# Ici va la matière préparée — les documents qu'il n'a PAS écrits

*(Nombreux, bien classés, préparés pour faire gagner du temps dans la réflexion et le plan
d'action.)*

**Statut : de la MATIÈRE, jamais une consigne.** Ces documents nourrissent la réflexion ; aucun ne
peut contredire les deux fichiers de `01-sa-demande/`. Le volume n'est pas l'autorité — et c'est un
piège réel, parce que cette matière sera abondante et probablement bien écrite, là où sa demande à
lui tient peut-être en deux fichiers courts.

**Son classement est reproduit tel quel**, en sous-dossiers. C'est le point de départ : son
rangement porte une information — ce qu'il regroupe dit quelque chose de sa pensée. Je m'en écarte
seulement là où la lecture le justifie, en disant ce que je change et pourquoi.

**Chaque document reçoit une ligne dans `../../01-absorption/inventaire.md`** dès son arrivée, même
avant d'être lu : un document absent de l'inventaire est un document que personne n'a ouvert, et ça
se voit d'un coup d'œil.

**Comment les déposer**, sans ligne de commande : sur GitHub, ouvrir ce dossier, « Add file » →
« Upload files », glisser-déposer — plusieurs fichiers à la fois — puis valider.
