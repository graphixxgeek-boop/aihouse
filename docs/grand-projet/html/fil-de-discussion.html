Réponse courte — Quand le même bout de code est recopié à plusieurs endroits, un outil les repère. Une grappe, c'est UN bout de code et TOUS les endroits où il a été recopié. « 8 grappes » = 8 bouts de code différents qui traînent chacun en plusieurs exemplaires.
