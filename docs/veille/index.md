# VEILLE CONCURRENTIELLE — index

*(Créé le 2026-09-26, tâche #771.)*

**Ce que ce dossier est** : l'archive des passages de veille sur ce qui existe ailleurs — outils,
produits, publications — et ce qu'on en retient pour l'Agence.

**Ce qu'il n'est PAS** : un registre d'outil. Aucun script ne le remplit sur un rythme. Une veille
se fait quand une question se pose, jamais par calendrier — un passage de veille tous les quinze
jours produirait invariablement « rien de neuf », c'est-à-dire du bruit qui apprend à ne plus lire.

**La règle qui évite qu'il pourrisse** : un passage de veille n'entre ici que s'il conclut. Une
liste de liens sans « ce que ça change pour nous » est une trace, jamais une veille.
