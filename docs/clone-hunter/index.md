## `memoire.json` — le registre des décisions tranchées

Créé le 2026-10-02 (tâche #1452), **six jours après que l'outil ait reçu le mécanisme qui le lit**.
Il était cité dans le code de CLONE-HUNTER et imprimé dans ses rapports, mais n'existait pas :
`loadMemoire()` tolérant l'absence, l'outil se comportait comme si rien n'avait jamais été tranché.

Il est volontairement **vide** (`[]`) : aucun problème de duplication n'a encore été écarté avec
l'accord explicite de l'utilisateur. Un problème n'en sort que par une entrée portant
`accordUtilisateur` — l'agent ne peut pas se faire taire tout seul, et c'est le but.

`findMemoiresDeclareesSansFichier()` (`scripts/safe-export.mjs`) empêche désormais qu'un prochain
consommateur de ce mécanisme vive le même silence.
